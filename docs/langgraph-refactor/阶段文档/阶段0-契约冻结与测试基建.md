# 阶段 0：契约冻结与测试基建

> 归属：`docs/langgraph-refactor/阶段文档/阶段0-契约冻结与测试基建.md`
> 总纲依据：`docs/langgraph-refactor/总需求文档.md`（本文档任何条款与总纲冲突时，以总纲为准并走契约评审）

---

## 一、核心目标

阶段 0 是重构的**地基**：在动任何业务代码之前，先把"怎么演进 schema、怎么管理配置、怎么测试、协议是什么"四件事定死。本阶段**不做业务逻辑改动**，只做地基与安全补洞，为后续 5 个阶段提供可回归的安全网。

1. **O-0.1 契约冻结**：将 wire 协议与数据契约（SSE v1 信封、WS、pipeline_steps、doc_id 口径、chunk 结构、SearchHit、TaskStatus 状态机、队列消息、额度契约）正式文档化并冻结，后续阶段不得静默变更。
2. **O-0.2 迁移基建**：引入 Alembic 版本化迁移，替代 lifespan 内 `create_all + ALTER TABLE ADD COLUMN IF NOT EXISTS` 的 hack；为 `langgraph-checkpoint-postgres` 建 checkpoint 表。
3. **O-0.3 配置单一真相源**：`config.py` + `key_manager.py` 的 `os.getenv` 双解析收敛为 `pydantic-settings Settings` 单一真相源，带类型校验。
4. **O-0.4 测试安全网**：建立 `pytest + pytest-asyncio + testcontainers + CI`，为 domain 纯函数建立 golden 回归基线，重构全程可回归。
5. **O-0.5 安全底线**：补齐 `/api/v1/documents*`、`/tokens/usage` 的鉴权；建立 KB 作用域授权依赖（修复 `ChatSendRequest` 无 kb 权限校验）。

### 2.3 边界与约束

- 契约冻结后，**任何契约变更必须更新契约文档并触发相关阶段验收重跑**。
- 迁移引入 Alembic 后，`lifespan` 只做连通性校验与可选 seed，不得再写 DDL。
- 测试基建必须做到"本地一条命令跑全部测试"（`uv run pytest`），CI 与本地同源。

### 4.2 数据契约（本阶段冻结）

> 契约原文见总需求文档 §7。本阶段在代码层落地为类型/常量，杜绝"协议靠注释"。

**4.2.1 TaskStatus 枚举**（DB 迁移目标，阶段 2 落库）

```python
class TaskStatus(str, Enum):
    PENDING = "pending"; PROCESSING = "processing"
    PARSED = "parsed"; INDEXING = "indexing"
    READY = "ready"; FAILED = "failed"
# 迁移表：PENDING→PROCESSING→PARSED→INDEXING→READY|FAILED；任意→FAILED；FAILED→PENDING(重试)
```

**4.2.2 pipeline_steps 契约**

```python
PIPELINE_STEPS_ORDER = ["upload", "mineru", "chunking", "embedding", "es_write", "milvus"]
StepState = {status: Literal["pending","running","done","failed","skipped"],
             ts: float, target_index: str|None, target_collection: str|None,
             count: int|None, error: str|None}
# 校验器：非法 key / 非法 status 抛异常；本阶段开始停用 worker 写 task.status.lower() 污染 JSONB
```

**4.2.3 SSE v1 信封**（新增 error/heartbeat，旧字段保留向后兼容）

```jsonc
{"v":1, "t":"step",  "k":"intent|retrieval|fusion|answer", "s":"pending|running|done|failed", "elapsed_ms":0, "metrics":{}}
{"v":1, "t":"text",  "c":"token片段"}
{"v":1, "t":"cite",  "citations":[{idx,doc_id,title,snippet,md5}]}
{"v":1, "t":"done",  "conversation_id":"…", "message_id":"…"}
{"v":1, "t":"error", "code":"…", "message":"…", "retryable":false}   // 新增
{"v":1, "t":"heartbeat"}                                              // 新增
```

**4.2.4 checkpoint 表 DDL**（Alembic 落库）

```sql
-- checkpoints / checkpoint_blobs，schema 与 langgraph-checkpoint-postgres 4.x 的
-- AsyncPostgresSaver 期望一致；由 Alembic 迁移管理，不得依赖 .setup()
```

**4.2.5 doc_id 口径（冻结声明，阶段 3 执行迁移）**

`doc_id = meta.article_id 兜底 md5[:8]`，全链路一致；ES `_id=chunk_id`、Milvus PK=`chunk_id`。

### 4.3 本阶段变更的契约点

- SSE 帧增加 `v` 字段与 `t:error`、`t:heartbeat`（向后兼容，旧前端可忽略未知字段）。
- `/tokens/usage` 从无鉴权变为 admin 鉴权（破坏性，前端如有调用需同步，验收用例覆盖）。
- `/api/v1/documents*` 增加鉴权（破坏性，前端 api 拦截器已带 token，正常路径不受影响）。
